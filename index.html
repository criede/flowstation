FlowStation APT-Repository

Rust-TETRA-Basisstation, als Paket flowstation mit bluestation-bs, Konfigurationsvorlage und systemd-Dienst. Daily-Pakete sind Entwicklungsversionen. Asterisk und SDR-Hardwaretreiber sind nicht enthalten; der passende SoapySDR-Treiber muss installiert sein.

Installation

Die URL unten gilt fuer criede/flowstation. Bei einem weiteren Fork muss sie an dessen Pages-Adresse angepasst werden.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://criede.github.io/flowstation/flowstation-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/flowstation.gpg > /dev/null
sudo chmod 0644 /etc/apt/keyrings/flowstation.gpg
. /etc/os-release
arch=$(dpkg --print-architecture)
echo "deb [arch=$arch signed-by=/etc/apt/keyrings/flowstation.gpg] https://criede.github.io/flowstation $VERSION_CODENAME main" \
  | sudo tee /etc/apt/sources.list.d/flowstation.list
sudo apt update
sudo apt install flowstation
sudo editor /etc/flowstation/config.toml
sudo systemctl enable --now bluestation-bs.service
journalctl -u bluestation-bs.service -f

Vor dem ersten Start Frequenzen, Stationskennung und Hardware konfigurieren. Die Paketinstallation aktiviert und startet den Dienst nicht.

Versionen und Updates

sudo apt upgrade installiert neuere Pakete. apt list -a flowstation zeigt verfuegbare Versionen. Mit sudo apt install flowstation=VERSION ist ein gezielter Rollback moeglich, mit sudo apt-mark hold flowstation eine Sperre. Daily-Pakete sortieren nach dem stabilen Release derselben Projektversion.

Aufbewahrung: alle Dailys fuer 7 Tage, danach woechentlich bis 30 Tage, monatlich bis 365 Tage. Das neueste Daily und stabile Releases bleiben erhalten.
